# Contributing

Install Node 22, run `npm ci`, and use `npm run lint`, `npm test`, and `npm run build` before opening a pull request. Keep changes focused, add regression coverage, and update the relevant documentation when behavior changes.

Use Conventional Commit subjects such as `feat:`, `fix:`, `test:`, `docs:`, `chore:`, or `ci:`. Do not include credentials, provider tokens, generated database files, or private endpoint URLs in issues or patches.
